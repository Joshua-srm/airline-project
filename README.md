# airline-project
project on airline management and flight booking
The Airline Ticket Booking & Flight Management System is a web-based application designed to manage airline operations and allow customers to book flight tickets efficiently.
This project provides separate interfaces for:
👤 Customers – to search and book flights
🛠️ Admin – to manage flights and airline data
It demonstrates core concepts of web development, including frontend design and backend logic using Python.
🚀 Features
👤 Customer Module
Search available flights
View flight details
Book tickets
User-friendly interface
🛠️ Admin Module
Add new flights
Update flight information
Delete flights
Manage airline schedules
🛠️ Technologies Used
Frontend: HTML, CSS
Backend: Python (Flask)
Version Control: Git & GitHub
